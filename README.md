# LUCT Community Library Management System

A React-based web application for managing a community library.

The system allows users to view available books, borrow books, manage stock transactions, and manage library accounts based on their role.

## Features

- Role-based login
- Guest account registration
- Guest book borrowing
- Book availability display
- Most Trending Books slideshow
- Book cover images
- Book management
- Add, update, and delete books
- Stock arrival records
- Book borrowing records
- Transaction history
- Borrower identification
- User management
- Administrator privileges
- Librarian privileges
- Protected administrator account
- Duplicate membership ID prevention
- Form validation
- Browser localStorage data persistence
- Responsive design for desktop and mobile devices
- React Router page navigation

## Technologies Used

- React
- JavaScript
- JSX
- React Router
- Vite
- CSS
- Browser localStorage
- HTML
